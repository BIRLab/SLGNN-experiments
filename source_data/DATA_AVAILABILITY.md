# Data availability / 数据可用性

The available numerical source data underlying Figs. 4--6 and Tables 1--3,
together with a panel-by-panel index and archived figure files, are publicly
available in the `source_data` directory at
https://github.com/BIRLab/SLGNN-experiments/tree/main/source_data.
For Fig. 4b, g and h, the original vector figure files are provided; the
underlying numerical simulation arrays were not retained in the available
archive. The photographic sequence shown in Fig. 7 is also provided;
numerical hardware logs are not included. Data provenance, units and
availability limits are documented in the repository.

图4--6和表1--3现有的数值源数据、逐面板索引及归档配图文件已在上述仓库
`source_data` 目录公开。图4b、g、h提供原始矢量图，其数值仿真数组未保留在
现有归档中。图7提供论文所示的照片序列，不包含硬件数值日志。
数据来源、单位和完整性限制在仓库中说明。

# Code availability / 代码可用性

The MATLAB code for the SLGNN experiments and source-data export and
visualization scripts are publicly available at
https://github.com/BIRLab/SLGNN-experiments under the BSD-3-Clause license.
The MATLAB version, dependencies and execution instructions are documented
in the repository README.

SLGNN 实验 MATLAB 代码及数据导出、查看脚本已在上述仓库公开，采用
BSD-3-Clause 协议。环境、依赖与运行方式见仓库 README。
